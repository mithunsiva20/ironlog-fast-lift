# Lift Log

Build a mobile-first gym workout tracking app focused on strength and weightlifting, optimized for fast in-gym logging with sets, reps, weight, previous performance autofill, rest timer, and personal record tracking.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://ironlog-fast-lift.lovable.app
